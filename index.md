- Either create a dataset from given source folder (probably created by spider) with numbered files containing Q&A cards or something similar; then it would execute the fine-tuner based on this static data.

# Laegna AI Trainer: Fine-Tuning & Dataset Creation

_This is the CoPilot follow-up._

## Core Purpose
Laegna AI Trainer serves as the training module for AI fine-tuning, leveraging deep learning frameworks like **LitGPT** and **Hugging Face**.

### Training Methods
- **Static Dataset Training**:
  - Extracts data from a structured source folder (generated by Laegna Spider).
  - Creates numbered Q&A files for model fine-tuning.
  - Executes training based on predefined datasets.

- **Dynamic AI Fine-Tuning**:
  - Generates Q&A cards in real time.
  - Feeds adaptive content to fine-tuning models.
  - Supports flexible learning configurations.

### Integration & Dependencies
- **Used by**: Laegna Spider (as the AI model trainer).
- **Drivers**: Implements compatibility with various AI frameworks for extensibility.

With this setup, Laegna AI Trainer ensures modular fine-tuning capabilities, supporting structured learning from collected datasets while enabling dynamic adjustments for evolving AI models.
